Supersets.

- Superset with… in an exercise's menu groups it with another exercise of the day. A superset shows as one frame around its exercises' cards.
- Logging a set in a superset moves on to the next exercise of the round. The rest countdown starts only when the round is over, and it lasts the longest rest of the superset's exercises. The panel says where the next set is, as in "Set 2 of 4 · then Rows".
- Drag an exercise into a superset's frame to add it, within the frame to change the order of the round, or out of the frame to take it out. The handle on the superset's header moves the whole superset.
- Copying a past workout keeps its supersets.
- The FitNotes import now brings superset groups over. Import the same backup again to add them to the days you have not changed in Setlist.
