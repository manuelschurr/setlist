The first release.

- The whole day on one screen, with a docked panel that edits the highlighted set and large plus and minus buttons.
- Changing a set's weight or reps also changes the later planned sets of that exercise that still held the old value.
- Logging the last set of an exercise moves straight on to the next unfinished one, with Undo instead of a confirmation.
- Drag an exercise by its handle to reorder.
- Copy a past workout, see last time's values next to each set, and a rest countdown with a notification and a vibration at the end.
- Import a FitNotes backup (History, then Data), and export or restore a Setlist backup.
