Google Drive backup.

- History, then Data, then Google Drive backup: choose a backup file in Google Drive once, and Setlist writes the whole database over it each time you leave the app after a change. The Drive app on the phone uploads it, so Setlist needs no Google sign-in.
- The same screen shows the last backup or why it failed, and offers Back up now, Restore from this backup, Change file and Stop backing up.
- On a new phone, Restore Setlist backup picks the file from Drive.
- Debug builds now install as a separate app, Setlist debug.
