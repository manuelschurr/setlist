Weekly Google Drive backups.

- Google Drive backup now backs up into a folder and keeps one file per week in it, named by the Monday the week starts, such as `Setlist week of 2026-11-16.sqlite`. Each backup writes over this week's file only, so a bad import or a wrong restore can no longer overwrite your only backup.
- After updating, open History, then Data, then Google Drive backup, and tap Choose backup folder once. In the picker, open My Drive and pick a folder or create one, such as Setlist backups. If you had a backup file linked in 0.2 or 0.3, backups keep going to it until you choose a folder, and the old file stays in Drive.
- Restore latest backup brings back the newest weekly file. Restore an earlier week opens the picker in the backup folder so you can pick an older one, and Restore Setlist backup in History opens there too.
- Setlist never changes or deletes an earlier week's file. Delete old ones in Drive if you need the space.
